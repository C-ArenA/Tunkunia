# Bundled document fonts

These fonts are kept with the Typst sources so macOS and Linux builds use the
same metrics and produce reproducible page layouts.

- `LektonNerdFont-*.ttf` is Lekton patched by Nerd Fonts. Lekton is distributed
  under the included SIL Open Font License 1.1 without a Reserved Font Name. See the
  [Nerd Fonts license inventory](https://github.com/ryanoasis/nerd-fonts/blob/master/bin/scripts/lib/fonts.json).
- `texgyretermes-*.otf` and `texgyrecursor-*.otf` are distributed under the
  GUST Font License included in this directory. The upstream family README
  files are included alongside it.

Do not add machine-specific font paths to the document or editor settings.
